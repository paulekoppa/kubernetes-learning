# Project 6 — RBAC, Service Accounts, and Security Contexts

## Overview
This project covers the Kubernetes identity and authorization model.
We secure the API layer using Role-Based Access Control (RBAC),
isolate workload identities using ServiceAccounts, and harden
container runtime behaviour using Security Contexts.

## Topics Covered
- ServiceAccounts and pod identity
- Roles and ClusterRoles
- RoleBindings and ClusterRoleBindings
- kubectl auth can-i for access verification
- Security Contexts (runAsNonRoot, readOnlyRootFilesystem, capabilities)
- Hardening the full 3-tier stack
